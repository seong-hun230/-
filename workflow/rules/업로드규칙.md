# 업로드 규칙

> Claude 는 발행 관련 작업 전에 이 문서를 반드시 읽고 따른다.

## 절대 규칙
- **발행은 항상 초안을 먼저 보여주고, 사용자가 '승인'이라고 한 뒤에만 예약한다.**
  1. 초안 `out/publish.json` 작성
  2. `zernio.py show out/publish.json` 결과를 사용자에게 그대로 보여줌
  3. 사용자가 "승인"이라고 답함 → `zernio.py approve` → `zernio.py publish`
- 승인 뒤에 무엇이든 바뀌면 다시 보여주고 다시 승인받는다 (스크립트가 자동으로 막는다).
- '승인' 이외의 말("좋네요", "괜찮아요")은 승인이 아니다. 애매하면 "승인으로 볼까요?"라고 묻는다.
- API 키는 화면에 출력하지 않는다. 키는 사용자가 자기 터미널에서 `zernio.py set-key` 로 직접 저장한다.

## 채널별
- **해시태그 5개까지만.** 검색될 단어는 캡션 첫 줄에.
- 정각보다 **19:23 처럼 분을 섞어** 예약한다.
- 인스타 릴스: 예약 시각 **2~3분 뒤**에 올라온다(인스타 처리 시간). "지금 바로" = 1분 뒤 예약.
- 인스타 배경음악: `zernio.py audio` 로 **검색되는 곡만** 가능. 원하는 곡이 없으면 비슷한 분위기로 바꾸고 사용자에게 알린다. 볼륨 기본 10.
  - 음악은 인스타를 **'페이스북 로그인' 방식으로 연결**해야만 된다 (설치안내 참고).
- 유튜브 쇼츠: **커버 사진 자동 지정 불가** → `thumbnail.py prepend` 로 맨 앞 0.1초에 썸네일을 붙인 영상을 올리고, 올린 뒤 유튜브 앱에서 그 장면을 커버로 고른다.
- 쓰레드: 사진은 **첫 번째 글 안에만**.

## 댓글 키워드 → 자동 DM
- 키워드는 짧고 쉽게(예: 홈페이지, 워크플로우). '포함' 방식이라 "홈페이지 주세요"도 걸린다.
- 팔로우한 분께만 링크 DM, 아직 안 한 분께는 "팔로우해 주시면 더 많은 정보 드릴게요" + [팔로우했어요] 버튼 먼저.
- DM 으로 키워드를 보내도 같은 답이 가게 켠다(`alsoMatchInDms`).
- 게시물 예약할 때 같이 걸어 두면 올라가는 순간 자동으로 켜진다.
- 올린 뒤엔 **본인 말고 다른 계정**(팔로우한 계정 · 안 한 계정 둘 다)으로 테스트 댓글을 달아 보라고 사용자에게 안내한다.
