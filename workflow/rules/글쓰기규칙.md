# 글쓰기 규칙 (블로그 · 쓰레드 · 캡션)

> Claude 는 글을 쓰기 전에 이 문서를 반드시 읽고 따른다.
> 사용자가 피드백을 주면 맨 아래 "피드백 기록"에 추가하고 다음 글부터 적용한다.

## 절대 규칙
- **영상에서 한 말만 재료로 쓴다.** 재료는 `cut.transcript.json`(또는 `.txt`) 뿐이다.
- **없는 사실·숫자·경험담은 절대 쓰지 않는다.** 그럴듯한 사례를 지어내지 않는다.
- 영상에 없는 내용이 꼭 필요하면 글에 넣지 말고, 사용자에게 "이 부분은 영상에 없어서 확인이 필요합니다"라고 따로 묻는다.
- 초안을 넘길 때 "영상에 없는데 들어간 문장"이 없는지 스스로 대조하고, 대조 결과를 한 줄로 보고한다.

## 네이버 블로그
- 제목 **앞쪽**에 검색될 키워드 하나.
- 사진 3~5장 (`thumbnail.py frames` 로 영상에서 뽑기). 본문 중 사진 자리를 `[사진1]` 처럼 표시.
- 강조 문장은 **굵게 + 색 하나만** (원고에는 `**굵게**` 와 `(색: 빨강)` 표시).
- 글 끝에 가게·회사 지도 넣기 → 원고 끝에 `[지도: 장소명]` 표시 (네이버 에디터의 '장소' 버튼으로 직접 넣음).
- 결과 파일: `out/blog.md`

## 쓰레드
- `workflow/rules/말투샘플/` 에 있는 사용자의 글을 '말투 기준'으로 삼아 따라 쓴다. 샘플이 없으면 사용자에게 2~3편 달라고 요청한다.
- 구성은 영상과 똑같이: **누구에게 → 바로 방법 → 짧은 내 생각.**
- 3개로 나눌 때 각 글 500자 이내. 사진(카드뉴스)은 **첫 번째 글에만**.
- 결과 파일: `out/threads.md`

## 인스타 캡션 · 유튜브 설명
- 해시태그는 **5개까지만**. 대신 검색될 단어를 캡션 첫 줄과 영상 속 말에 넣는다.
- 유튜브 쇼츠 제목은 검색되게 한 줄. 자료 링크는 설명란과 첫 댓글에.
- 결과 파일: `out/caption_reels.txt`, `out/youtube_description.txt`
