# 설치 안내 (처음 한 번만)

가장 쉬운 방법: 이 폴더를 Claude Code 로 열고 **"workflow/설치안내.md 대로 설치해줘"** 라고 말하세요.
직접 하려면 아래 순서대로 하면 됩니다.

## 1. 필요한 프로그램 3가지
| 프로그램 | 하는 일 |
|---|---|
| Python 3.10 이상 | 스크립트 실행 |
| FFmpeg | 영상 자르기·합치기 |
| faster-whisper 등 (pip 패키지) | 받아쓰기, 썸네일, 제르니오 연결 |

### Windows
1. 시작 메뉴에서 **"PowerShell"** 검색 → 클릭해서 엽니다.
2. 아래 두 줄을 한 줄씩 붙여넣고 Enter:
   ```
   winget install Python.Python.3.12
   winget install Gyan.FFmpeg
   ```
3. PowerShell 창을 **닫았다가 다시 엽니다** (설치한 프로그램을 인식시키기 위해).
4. 이 폴더로 이동한 뒤 패키지 설치:
   ```
   cd "이 폴더 경로"
   python -m pip install -r workflow/requirements.txt
   ```

### Mac
1. **응용 프로그램 → 유틸리티 → 터미널** 을 엽니다.
2. Homebrew 가 없다면 https://brew.sh 첫 화면의 명령을 붙여넣어 설치합니다.
3. 아래를 붙여넣고 Enter:
   ```
   brew install python ffmpeg
   cd "이 폴더 경로"
   python3 -m pip install -r workflow/requirements.txt
   ```
   (Mac 에서는 안내 문서의 `python` 을 `python3` 으로 바꿔 쓰면 됩니다.)

### 설치 확인
```
python --version
ffmpeg -version
python -c "import faster_whisper, requests, PIL; print('OK')"
```
세 줄 모두 오류 없이 나오면 끝입니다.

- 처음 받아쓰기를 할 때 받아쓰기 모델(약 3GB)을 자동으로 내려받습니다. 인터넷이 연결된 상태에서 몇 분 기다리면 됩니다.
- 컴퓨터가 느리면 받아쓰기에 `--model medium` 을 붙이면 더 빠릅니다 (정확도는 조금 낮음).
- 한글 글꼴은 Windows 는 맑은 고딕, Mac 은 애플 SD 고딕 Neo 를 자동으로 씁니다. 다른 글꼴을 쓰려면 글꼴 파일을 `workflow/assets/font.ttf` 로 복사하세요.

## 2. 제르니오 준비 (STEP 9 발행을 쓸 때만)
> 아래 요금·화면 이름은 노션 원문(2026년 10월 기준) 내용입니다. 바뀌었을 수 있으니 가입할 때 한 번 확인하세요.

1. **가입**: zernio.com 가입 → 대시보드 **Connections** 에서 인스타·유튜브·쓰레드를 연결합니다.
2. **요금**: 연결 계정 2개까지 무료, 3번째부터 계정당 월 6달러(원문 기준). 게시물 수 제한은 없음.
3. **API 키 만들기**: 대시보드 **API Keys** → 새 키 만들기 → 키를 복사합니다.
4. **키 저장** (채팅창에 붙여넣지 마세요): 위 1번에서 연 PowerShell/터미널에서
   ```
   python workflow/scripts/zernio.py set-key
   ```
   를 실행하고, 키를 붙여넣은 뒤 Enter. 화면에 키가 보이지 않는 게 정상입니다.
   키는 내 컴퓨터의 `사용자폴더/.config/zernio/api_key` 에만 저장됩니다.
5. **연결 확인**:
   ```
   python workflow/scripts/zernio.py accounts
   ```
   연결한 계정 목록이 나오면 성공.

### 인스타 릴스에 배경음악까지 넣으려면 (중요)
- 인스타를 **'페이스북 로그인' 방식**으로 연결해야 음악이 들어갑니다. '인스타 로그인' 방식이면 발행은 되지만 음악은 막힙니다.
- 먼저 **인스타 앱 → 프로필 편집 → 페이지** 에서 내 페이스북 페이지를 연결해 둡니다 (다른 사업 페이지에 붙이면 안 됨).
- 페이스북 권한 화면에서는 **페이지와 인스타 계정을 둘 다 체크**합니다. 페이지만 체크하면 인스타가 목록에 안 뜹니다.
- 이미 인스타 로그인 방식으로 연결했다면, 그 연결을 **해제하고 다시** 페이스북 방식으로 연결합니다.
- 제르니오 화면의 'Facebook' 카드를 따로 누르면 계정이 하나 더 늘어 요금이 붙습니다. **인스타 카드에서** 연결하세요.
