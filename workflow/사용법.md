# 사용법 — Claude Code 에 이렇게 말하세요

준비: `workflow/설치안내.md` 를 한 번 끝내 두세요.
촬영본(mp4/mov)은 이 폴더 아무 곳에 넣거나, Claude Code 창으로 끌어다 놓으면 됩니다.

## 한 번에 전체
```
이 영상으로 4개 채널 콘텐츠 만들어줘. 영상: 촬영본.mp4
```
Claude 가 `projects/날짜_제목/` 폴더를 만들고 STEP 2부터 순서대로 진행하며, 단계마다 결과를 보여줍니다.

## 단계별로 (노션 원문 문장 그대로 써도 됩니다)
| STEP | 이렇게 말하기 |
|---|---|
| 1 대본 | `○○ 주제로 릴스 대본 써줘. 한 문장에 한 줄로.` |
| 2 받아쓰기 | `이 영상 받아쓰기 해줘. 단어마다 시작·끝 시각까지 적어줘.` |
| 3 컷 편집 | `말 없는 구간 잘라줘. 같은 문장을 두 번 읽은 곳은 뒤에 읽은 쪽만 남기고, 문장 사이 정적은 0.05초 정도만 남겨줘.` |
| 3 검증 | `완성본 다시 받아쓰기해서 말이 잘리거나 두 번 나오는 곳 없는지 확인해줘.` |
| 4 꾸미기 | `상단에 고정 제목 2줄 넣고, 자막은 2~4단어씩 짧게 끊어줘. 내가 말하는 순간에 맞춰 번호 배지와 키워드를 하나씩 띄우고, 명령어는 검은 터미널 박스에 타이핑되게 해줘. 효과음과 줌 전환도 넣어줘.` |
| 5 숏폼 | `이 롱폼에서 30~45초짜리 숏폼 4개 뽑아줘. 한 편에 정보 하나만, 앞 맥락 없이도 이해되는 구간으로 골라줘.` |
| 6 블로그 | `이 영상 내용으로 네이버 블로그 글 써줘. 영상에서 한 말만 쓰고, 없는 사실이나 숫자는 넣지 마. 제목 앞에 '○○' 키워드 넣어줘.` |
| 6 쓰레드 | `이 영상 내용으로 쓰레드 글 3개로 나눠 써줘. 말투는 말투샘플 기준으로.` |
| 7 썸네일 | `썸네일 3개 만들어줘. 질문형·숫자형·손해형으로.` |
| 8 검토 | `검토할 것 정리해줘.` → 직접 확인 후 `검토 끝` |
| 9 릴스 | `이 완성본 영상을 제르니오로 인스타 릴스에 오늘 19시 23분에 예약해줘. 커버는 2번 썸네일, 해시태그는 5개까지. 배경음악은 잔잔한 피아노 곡 찾아서 볼륨 10으로.` |
| 9 쇼츠 | `같은 영상을 유튜브 쇼츠로도 올려줘. 제목은 검색되게 한 줄로, 자료 링크는 설명란과 첫 댓글에.` |
| 9 쓰레드 | `이 글을 쓰레드에 3개로 나눠서 오늘 20시 47분에 예약해줘. 카드뉴스 사진은 첫 번째 글에.` |
| 9 자동 DM | `이 릴스에 댓글 자동 DM 걸어줘. 키워드는 '워크플로우', DM에는 감사 인사랑 자료 링크 버튼 하나, 댓글에는 'DM으로 보내드렸어요' 답글. 팔로우한 분께만 보내고, 안 한 분께는 팔로우 부탁 메시지부터.` |

발행(STEP 9)은 Claude 가 초안을 먼저 보여줍니다. 내용이 맞으면 **"승인"** 이라고 답해야 예약됩니다.

## 피드백은 규칙으로 남기기
```
방금 내가 준 피드백, 편집 규칙 문서(md)에 적어 두고 다음 영상부터 이 기준으로 똑같이 편집해줘.
```
규칙 문서: `workflow/rules/편집규칙.md`, `글쓰기규칙.md`, `업로드규칙.md`.
이 규칙 문서가 쌓일수록 결과가 좋아집니다.

## 폴더 구조
```
CLAUDE.md                  Claude 가 항상 읽는 규칙 요약
.claude/skills/            단계별 작업 지침 (STEP 1~9)
workflow/scripts/          실제로 영상·글·발행을 처리하는 프로그램
workflow/rules/            편집·글쓰기·업로드 규칙 (피드백이 쌓이는 곳)
workflow/templates/        설정 예시, 대본·검토 체크리스트
workflow/assets/           글꼴, 로고, 효과음
projects/날짜_제목/         영상별 작업 폴더 (raw 원본 / work 중간 / out 완성)
```
