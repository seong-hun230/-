# 2본 2팀 워킹순번표 설치 방법

구글 시트에 한 번만 설치하면 인터넷 주소(링크)가 하나 생깁니다.
그 링크를 카톡 단톡방에 올리면 직원 누구나 **로그인 없이** 같은 순번표를 보고 체크할 수 있습니다.
기록은 설치한 사람의 구글 시트에 자동으로 쌓입니다.

준비물: 구글 계정 1개 (설치하는 사람만 필요), PC

---

## 1단계. 구글 시트 만들기

1. PC 크롬에서 `sheets.google.com` 접속 → 구글 로그인
2. 왼쪽 위 **빈 스프레드시트** (+ 모양) 클릭
3. 왼쪽 위 "제목 없는 스프레드시트" 글자를 눌러 이름을 **2본 2팀 워킹순번표** 로 바꾸기

## 2단계. 코드 붙여넣기

1. 시트 위쪽 메뉴에서 **확장 프로그램** → **Apps Script** 클릭 (새 탭이 열림)
2. 왼쪽 파일 목록의 **Code.gs** 가 열려 있는 상태에서, 오른쪽 편집창의 내용을 전부 지우기 (Ctrl+A → Delete)
3. 이 폴더의 `Code.gs` 파일 내용을 전부 복사해서 붙여넣기
4. 왼쪽 **파일** 글자 옆 **+** 버튼 → **HTML** 클릭 → 이름에 `Index` 입력 후 Enter
   - 대문자 I 로 정확히 `Index` 라고 입력합니다 (.html 은 자동으로 붙음)
5. 새로 생긴 **Index.html** 의 내용을 전부 지우고, 이 폴더의 `Index.html` 파일 내용을 전부 복사해서 붙여넣기
6. 위쪽 **디스크(저장) 아이콘** 클릭 또는 Ctrl+S

## 3단계. 웹 앱으로 배포 (링크 만들기)

1. 오른쪽 위 파란 버튼 **배포** → **새 배포** 클릭
2. "유형 선택" 옆 **톱니바퀴** 아이콘 → **웹 앱** 선택
3. 아래처럼 설정
   - 설명: `워킹순번표` (아무거나)
   - 다음 사용자 인증 정보로 실행: **나 (본인 이메일)**
   - 액세스 권한이 있는 사용자: **모든 사용자**  ← 이걸 골라야 직원들이 로그인 없이 씁니다
4. **배포** 클릭
5. "액세스 승인" 창이 뜨면 → **액세스 승인** → 본인 구글 계정 선택
6. "Google에서 확인하지 않은 앱" 경고가 나오면 → 왼쪽 아래 **고급** → **워킹순번표(으)로 이동(안전하지 않음)** → **허용**
   - 본인이 직접 만든 코드라서 나오는 정상 경고입니다
7. 완료 창의 **웹 앱 URL** 오른쪽 **복사** 클릭 → 이 주소가 순번표 링크입니다

## 4단계. 카톡 단톡방에 공유

1. 복사한 링크를 단톡방에 붙여넣고 보내기
2. 단톡방 상단 공지로 등록해 두면 매번 찾기 편합니다
   (메시지 길게 누르기 → **공지**)
3. 직원들은 링크를 누르면 바로 순번표가 열립니다
   - 화면 맨 위에 "이 애플리케이션은 Google이 아닌 사용자가 만들었습니다" 같은 회색 안내줄이 보이는데 정상입니다
   - 휴대폰 홈 화면에 추가해 두면 앱처럼 쓸 수 있습니다
     (크롬/삼성인터넷 메뉴 → **홈 화면에 추가**)

---

## 사용 방법

1. 손님이 오면 화면 맨 위 **"○○○ 워킹 받음 체크"** 버튼 → **네, 체크합니다**
2. 받은 사람 이름 옆에 **몇 월 며칠 몇 시**에 받았는지 자동 기록되고, **다음 순번**이 바로 표시됩니다
3. **카톡 알림 문구 복사** → 단톡방에 붙여넣기 하면 아래처럼 알림이 갑니다
   ```
   [2본 2팀 워킹]
   10월 25일(일) 14:32 홍명숙 실장 워킹 받음
   ▶ 다음 순번: 김기엽 부장
   순번표: (링크)
   ```
4. 화면을 열어 둔 다른 직원 폰은 30초마다 자동 새로고침되고, 새 기록이 생기면 "새 기록 … 다음 순번은 …" 안내가 뜹니다
5. 담당자가 자리에 없으면 **자리에 없음 · 이번 순번 건너뛰기** → **네, 건너뜁니다**
   - 이번 차례만 다음 사람에게 넘어가고, 다음 바퀴에는 원래 순서대로 돌아옵니다
   - 받은 건수에는 들어가지 않고, 기록에 "건너뜀(부재)"로 남습니다 (시트 **기록** 탭 D열 '구분')
6. 잘못 눌렀으면 아래 **마지막 기록 취소** → **네, 취소합니다** (순번이 한 칸 되돌아감)
7. 두 사람이 거의 동시에 체크하면 먼저 누른 1건만 기록되고, 늦게 누른 사람에게는 "다른 직원이 먼저 체크했다"고 안내됩니다

## 담당자 이름·순서 바꾸기

- 구글 시트 아래쪽 **순번** 탭에서 A열 이름을 고치거나 줄을 추가/삭제하면 됩니다 (위에서부터 순서)
- 다시 배포할 필요 없이, 순번표 화면에서 새로고침하면 바로 반영됩니다
- **순번** 탭과 **기록** 탭은 순번표 링크를 처음 열 때 자동으로 만들어집니다
- 기록 탭의 날짜·담당자는 그대로 엑셀처럼 확인·출력할 수 있습니다

## 코드를 나중에 고쳤을 때 (링크 유지)

**배포** → **배포 관리** → 연필(수정) 아이콘 → 버전: **새 버전** → **배포**
→ 링크 주소는 그대로이고 내용만 바뀝니다. ("새 배포"를 누르면 링크가 새로 생기니 주의)
