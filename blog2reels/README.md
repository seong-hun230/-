# 블로그 → 릴스 자동 제작 앱

블로그 글 주소만 넣으면 내용을 분석해서 **9:16 세로 릴스 영상 + 커버 + 캡션**을 자동으로 만들어 줍니다.
네이버 블로그 · 티스토리 · 브런치 · 워드프레스 · 일반 웹 글을 지원합니다.

## 만들어지는 것 (업로드 세트)

| 파일 | 내용 |
|---|---|
| `<이름>.mp4` | 1080×1920 · 30fps · 라우드니스 -14 LUFS 릴스 영상 |
| `<이름>_커버.jpg` | 훅 문구가 크게 들어간 커버 |
| `캡션_복붙용.txt` | 인스타 캡션 + 해시태그 + 업로드 전 체크사항 |
| `storyboard.txt` | 컷 구성표 (고쳐서 다시 렌더 가능) |
| `검수시트.jpg` | 컷마다 [실제 화면 + 자막]을 나란히 놓은 검수용 시트 |
| `컨택트시트.jpg` | 블로그 사진 번호표 (사진 바꿀 때 참고) |

## 영상 형식 (릴스 자동화 앱과 같은 '100만 조회수 문법')

- **0프레임 자막** · 훅 3컷 `1.10 + 1.05 + 0.90 = 3.05초` 안에 훅 → 기대치 → 전환
- 본문 컷 **1.9초** · 마지막 **루프컷 2.0초** (첫 컷 사진으로 돌아가 자연스럽게 반복) + **CTA**
- **1~3어절 워드팝 자막** (숫자·[대괄호] 글자는 노란색 강조) · 챕터 칩 · 상단 진행바
- **켄번즈 + 줌 펀치** · 화려한 전환(whip/flash/glitch/zoomblur) **3회 이하** · 효과음 **6개 이하**
- **BGM 드롭 = 챕터 전환** · BPM을 컷 길이에 맞춤(1.9초 = 4박) · 폰 스피커 기준 마스터링 · **-14 LUFS**
- 가로 사진은 잘라내지 않고 흐린 배경 위에 올림 → **검은 띠 없음**, 자막은 사진 아래에 배치
- 배경음악·효과음은 앱이 직접 합성 → 저작권 걱정 없음

## 설치와 실행 (처음 한 번)

### 윈도우
1. **파이썬 설치**: https://www.python.org/downloads/ 접속 → 노란 **Download Python** 버튼 클릭 → 받은 파일 실행
   → 설치 첫 화면 아래의 **"Add python.exe to PATH"** 체크 → **Install Now** 클릭
2. 이 `blog2reels` 폴더를 연 뒤 **`실행하기_윈도우.bat`** 를 더블클릭
   (처음에는 필요한 프로그램을 1~2분 설치합니다. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 클릭)
3. 브라우저가 자동으로 열립니다 (안 열리면 주소창에 `http://127.0.0.1:8800` 입력)

### 맥
1. https://www.python.org/downloads/ 에서 파이썬 설치
2. **`실행하기_맥.command`** 더블클릭 (처음에 "확인되지 않은 개발자" 경고가 뜨면 파일을 **우클릭 → 열기**)

> 검은 창(터미널)은 앱이 돌아가는 동안 닫지 마세요. 닫으면 앱이 종료됩니다.

## 사용법

1. **블로그 글 주소** 칸에 주소 붙여넣기 (예: `https://blog.naver.com/아이디/글번호`)
2. 영상 길이(15/20/30초) · 색감 · 배경음악 선택
3. **릴스 자동 제작** 클릭 → 진행 막대가 끝나면 영상 미리보기와 다운로드 버튼이 나옵니다
4. **자동 검수 결과**와 **검수 시트**를 보고 컷마다 "자막 내용이 화면에 실제로 보이는가" 확인
5. 안 맞는 컷이 있으면 아래 **스토리보드** 칸에서 **사진 번호만 바꾸고** → **수정한 스토리보드로 다시 만들기**

### 분석 방식 2가지 (화면의 '고급 설정')

| 방식 | 특징 |
|---|---|
| **Claude AI 분석 (권장)** | AI가 블로그 글과 사진을 **직접 보고** 컷마다 [사진 + 자막]을 짝지어 훅·챕터·캡션을 씁니다. Claude API 키 필요(유료 — 사진 수에 따라 영상 1편당 대략 100~400원 수준으로 추정, 정확한 요금은 콘솔에서 확인). |
| **규칙 기반 (무료)** | API 키 없이 동작. 사진 바로 앞뒤 문장을 그 사진의 자막으로 씁니다. 사진 내용을 이해하지 못하므로 **검수 필수**. |

Claude API 키 발급: https://console.anthropic.com → 로그인 → 왼쪽 **API Keys** → **Create Key** → 복사해서 앱의 'Claude API 키' 칸에 붙여넣기.
키는 파일로 저장되지 않습니다. 매번 입력하기 번거로우면 환경변수 `ANTHROPIC_API_KEY` 에 넣어 두면 자동으로 사용됩니다.

## 스토리보드 문법

```
@1 = img01.jpg
@card = 텍스트카드

# 소스 | 길이 | 자막(/ 로 조각 구분) | 옵션
1     | 1.10 | 성수동 신상 카페 / '온도' 솔직 후기 | hook
4     | 1.05 | 달지 않은 / [크림라떼] 맛집      | hook
3     | 0.90 | 핵심만 / 딱 정리했어요            | hook, trans=whip
2     | 1.90 | 성수역 3번 출구에서 / 도보 5분    | chapter=위치, zoom=out
card  | 1.90 | 월요일은 / 휴무예요               |
1     | 2.00 |                                   | loop, cta
```

- 옵션: `hook` `loop` `cta` `chapter=이름` `trans=cut|whip|flash|glitch|zoomblur|none` `zoom=in|out`
- 맨 위 `# 제목:` `# CTA:` `# CTA_SUB:` 줄을 고치면 상단 라벨·마지막 문구가 바뀝니다.
- 내 사진을 쓰고 싶으면 작업 폴더의 `src` 폴더에 넣고 `@9 = 내사진.jpg` 처럼 등록한 뒤 `9` 로 쓰면 됩니다.

## 명령줄로 쓰기 (선택)

```bash
python make_reels.py https://blog.naver.com/아이디/글번호 --length 20 --grade bright --bgm energetic
python make_reels.py --rerender output/작업폴더        # storyboard.txt 고친 뒤 다시 렌더
```

## 솔직한 한계

- **조회수를 보장하지 않습니다.** 형식을 강제할 뿐, 성과는 소재와 훅이 결정합니다.
- 규칙 기반 분석은 사진 내용을 이해하지 못합니다 → 검수 시트로 꼭 확인하세요.
- 숫자는 블로그 원문에 있는 것만 쓰도록 했고, 원문에 없는 숫자가 자막에 있으면 검수 결과에 표시됩니다.
- 분양·의료·금융·건강기능식품 등 **광고 심의 대상 업종**은 게시 전 표현 검토가 필요합니다(감지되면 경고).
- 비공개 글 · 로그인이 필요한 글 · 사진이 동영상만 있는 글은 가져오지 못합니다.
- 블로그 사진의 저작권·초상권은 게시하는 사람이 확인해야 합니다.
- 인스타 앱에서 트렌드 음원을 20~25% 볼륨으로 덧입히면 노출에 유리합니다.

```
blog2reels/
├─ app.py               브라우저 앱 (python app.py)
├─ make_reels.py        명령줄 실행
├─ core/
│  ├─ fetch.py          블로그 본문·사진 수집 (네이버 iframe·지연로딩 이미지 처리)
│  ├─ analyze.py        Claude / 규칙 기반 분석 → 스토리보드 (형식 규칙 강제)
│  ├─ storyboard.py     스토리보드 파서
│  ├─ render.py         프레임 합성 · 전환 · 인코딩 · 커버
│  ├─ text_fx.py        워드팝 자막 · 챕터칩 · CTA 그래픽
│  ├─ music.py          BGM · 효과음 합성, 폰 스피커 마스터링
│  ├─ verify.py         컨택트시트 · 검수시트 · 자동 점검
│  └─ pipeline.py       전체 흐름
├─ web/index.html       앱 화면
├─ assets/fonts/        Pretendard 폰트 (SIL OFL 1.1)
└─ tests/               테스트 (외부 접속 없이 전체 흐름 검증)
```
