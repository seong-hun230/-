# 대전 씨엘리오 스위첸 관심고객 등록 페이지 — 설정 방법

고객이 휴대폰으로 등록하면 **내 구글 시트에 한 줄씩 자동으로 쌓이는** 페이지입니다.
비용은 들지 않고, 구글 계정 하나만 있으면 됩니다. (약 10분)

## 들어 있는 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 고객이 보는 등록 페이지 (조감도, 혜택, 타입 소개, 등록 칸) |
| `Code.gs` | 등록 내용을 구글 시트에 저장하는 코드 |
| `설정방법.md` | 지금 보는 안내서 |

`index.html`을 더블클릭하면 컴퓨터에서 바로 미리 볼 수 있어요. 노란 띠에 **"미리보기 모드"**라고 나오면 정상입니다. 이 상태에서는 아직 저장되지 않아요.

---

## 1단계: 내 정보 넣기

`index.html`을 **메모장**으로 엽니다. (파일 오른쪽 클릭 → 연결 프로그램 → 메모장)
**Ctrl+F**로 `여기만 바꾸세요`를 찾으면 아래 내용이 나와요.

```js
phone: "",       // 상담 전화번호. 예: "042-000-0000"
agentName: "",   // 개인정보 처리자로 표시할 이름. 예: "대전 씨엘리오 스위첸 분양상담 홍길동"
```

따옴표 `" "` 안에 내 전화번호와 이름을 써요. 전화번호를 넣으면 **전화 상담 버튼**이 생깁니다.
다 썼으면 **저장(Ctrl+S)**합니다.

## 2단계: 구글 시트와 코드 준비

1. **sheets.google.com** 에서 **빈 스프레드시트**를 만들어요. 이름은 예를 들어 "씨엘리오 관심고객"으로 해요.
2. 위쪽 메뉴 **확장 프로그램 → Apps Script**를 눌러요.
3. 왼쪽 **Code.gs**의 내용을 모두 지우고, `Code.gs` 파일 내용을 통째로 붙여 넣어요.
   - 새 등록이 들어올 때 **이메일 알림**을 받고 싶다면 `NOTIFY_EMAIL: ''`의 따옴표 안에 내 이메일을 써요.
4. 왼쪽 **파일 옆 +** → **HTML**을 눌러 이름을 **index**라고 써요. (`.html`은 자동으로 붙어요)
5. 새로 생긴 index.html 내용을 모두 지우고, 1단계에서 고친 `index.html` 내용을 통째로 붙여 넣어요.
   (메모장에서 **Ctrl+A → Ctrl+C**, Apps Script에서 **Ctrl+V**)
6. 위쪽 **💾 저장** 아이콘을 눌러요.

## 3단계: 배포해서 주소 받기

1. 오른쪽 위 파란 **배포** → **새 배포**를 눌러요.
2. **유형 선택 ⚙️** → **웹 앱**을 골라요.
3. 이렇게 맞춰요.
   - 실행 주체: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → **액세스 승인** → 내 구글 계정을 골라요.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)** → **허용**을 눌러요. 내가 만든 코드라서 나오는 정상 경고예요.
5. 나오는 **웹 앱 URL**(…/exec로 끝남)을 복사해요. **이 주소가 고객에게 보낼 등록 페이지예요!** 🎉

## 4단계: 시험해 보기

1. 복사한 주소를 휴대폰에서 열어요.
2. 내 정보로 한 번 등록해 봐요.
3. 구글 시트에 **"관심고객"** 탭이 생기고 한 줄이 들어오면 성공이에요.

## 주소 활용 팁

- 블로그·카톡·문자에 그 주소를 붙여 넣으면 돼요.
- 주소 끝에 `?utm_source=블로그`처럼 붙이면, 시트의 **유입 경로** 칸에 어디서 들어온 고객인지 기록돼요.
  - 예: `…/exec?utm_source=naver_blog`, `…/exec?utm_source=kakao`
- 시트 맨 오른쪽 **상담 메모** 칸에는 통화 내용을 직접 적어 두면 좋아요.
- 같은 번호로 또 등록하면 **중복 여부** 칸에 "중복"이라고 표시돼요.

## 페이지를 고친 뒤에는

Apps Script에서 index.html을 고쳤다면 **배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포**를 눌러야 고객 화면에 반영돼요. 주소는 그대로 유지돼요.

---

## 꼭 확인할 것 ⚠️

- **분양가와 모델하우스 주소는 넣지 않았어요.** 블로그·홍보 자료에서는 빼는 것이 규칙이라, 페이지에는 "분양가와 계약 조건은 상담 시 안내"라고만 적었어요. 고칠 때도 금액이나 모델하우스 주소를 넣지 마세요.
- 혜택·입지 문구는 PDF(2026.11.24 기준) 내용만 썼어요. 자료가 바뀌면 `index.html`에서 같이 고쳐 주세요.
- **개인정보 보유 기간**은 "1년"으로 넣어 두었어요. 회사 방침이 다르면 `retention:` 값을 고쳐 주세요.
- 수집한 연락처는 상담 목적에만 쓰고, 기간이 지나면 시트에서 지워 주세요.
- 위쪽에 **"이 애플리케이션은 Google이 아닌 다른 사용자가 만들었습니다"** 안내 줄이 보이는 건 구글 웹 앱의 기본 표시예요. 없애고 싶다면 아래 '다른 곳에 올리기'를 쓰세요.

## (선택) 다른 곳에 올리기 — 구글 안내 줄 없이 깔끔하게

1. 3단계까지 마친 뒤, `index.html`의 `scriptUrl: ""` 따옴표 안에 웹 앱 주소(…/exec)를 붙여 넣고 저장해요.
2. **app.netlify.com/drop** 에 들어가 `index.html`이 들어 있는 폴더를 화면에 끌어다 놓아요.
3. 나오는 주소가 새 등록 페이지예요. 등록 내용은 똑같이 구글 시트에 쌓여요.
