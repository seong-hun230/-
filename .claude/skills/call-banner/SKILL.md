# 상담/방문예약 전화 유도 배너

분양 블로그의 목적은 **고객이 전화를 걸게 하는 것**이다(CLAUDE.md '전화 유도 원칙'). 이 스킬은 원고의 핵심 지점에 넣을 배너를 같은 디자인으로 빠르게 만든다.

## 1. 문구 원칙

- 기본 번호·문구: **상담/방문예약 1666-0992** (사용자가 다른 번호를 주면 그 번호).
- 분양가 숫자, 할인율, 평당가, 취득가 기준 금액, 모델하우스·견본주택 주소는 **배너에도 넣지 않는다.** 가격은 "특별할인공급 진행 중"으로만 쓰고, 자료에 할인·혜택 근거가 있을 때만 쓴다.
- 없는 마감 임박·한정 수량·잔여 세대 수를 만들지 않는다.
- 방문 위치는 "방문 위치는 예약하실 때 안내해 드립니다".
- 조감도·CG를 배경으로 쓰면 "이미지는 CG로 실제와 다를 수 있습니다"가 자동으로 들어간다(지우지 말 것).

## 2. 배너 4종 (원고 한 편 기본 구성)

| 순서 | 넣는 자리 | 형태 | 문구 방향 |
|---|---|---|---|
| 1 | 도입 직후 | `photo` (조감도 배경) | 단지명 + "*특별할인공급* 진행 중" + 입지 한 줄 + 전화 버튼 |
| 2 | 주력 타입·평면 뒤 | `navy` | "남은 호실과 *특별할인 조건* 확인" |
| 3 | 세제·대출·자격 등 조건 질문 뒤 | `navy` | "내 상황에도 *적용될까?*" |
| 4 | 마무리 | `photo` + `big_number` | "상담/방문예약" + 큰 번호 |

글이 짧으면 1·4번만, 길면 같은 형태로 1~2개를 더한다. 문단마다 넣지 않는다.

## 3. 만드는 방법

1. 설정 파일(JSON)을 만든다. 예시: `examples/daejeon_cielio.json`
   - `title`에서 `*별표*`로 감싼 말은 금색 강조, 줄바꿈은 `\n`
   - 한 줄 제목은 12자 안팎, 두 줄이면 줄마다 10자 안팎 (넘치면 글씨가 잘린다)
   - `eyebrow`(위 작은 글씨) 25자, `sub`(설명) 28자 이내
   - `cta_hint`(버튼 옆 작은 글씨)는 첫 배너에만 "터치하면 바로 연결"
2. 배경 사진이 있으면 준비한다. 분양 자료의 조감도(야경)를 내부용 머리글이 보이지 않게 잘라 쓴다.
3. 실행한다.

```bash
python .claude/skills/call-banner/scripts/make_banners.py \
  --spec 설정.json --out 출력폴더 --bg 조감도.jpg
```

- 결과: 배너마다 가로 1200px JPG + 한눈에 보는 `_preview.jpg`
- 필요한 것: 파이썬 playwright, Chromium(`/opt/pw-browsers/chromium` 또는 `BANNER_CHROMIUM`), ImageMagick. **Pretendard 글꼴은 없으면 npm으로 자동 설치**된다.
- 배경 사진 없이 `photo`를 고르면 남색 배경으로 바뀐다.

4. `_preview.jpg`를 열어 **반드시 눈으로 확인**한다. 글자 넘침·잘림, 오타, 번호가 맞는지 본다.

## 4. 원고에 넣는 방법

- 원고에는 `[배너 n: 파일명 — 사진 링크: tel:16660992]`로 자리를 표시하고, 배너 바로 아래 줄에 **"☎ 상담/방문예약 1666-0992"**를 글자로 한 번 더 적는다(워드에서는 tel 링크).
- 네이버: 올린 배너 사진 클릭 → 링크(🔗) → `tel:16660992`. 네이버가 전화 링크를 받지 않으면 관심고객 등록 페이지 주소를 건다. 이 동작은 아직 실제로 확인하지 못했으니, 처음 쓸 때 사용자에게 확인을 부탁한다.

## 5. 디자인 값 (바꿀 때 참고)

- 크기 1000×380(2배로 렌더) → 1200px JPG, 품질 90
- 글꼴: Pretendard — 제목 Black 900 / 64px, 버튼 Black 900 / 38px, 위 작은 글씨 ExtraBold 800 / 27px, 설명 Bold 700 / 27px, 큰 번호 Black 900 / 104px
- 색: 남색 #0b1f47→#13306b, 강조 금색 #ffd38f, 버튼 빨강 #e8372b
