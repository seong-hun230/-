# STEP 8 검토 — 이 단계만큼은 AI 에게 맡기지 않는다

Claude 는 판단하지 않고, 사람이 빨리 볼 수 있게 **확인할 지점만 모아** 준다.

1. `workflow/templates/검토_체크리스트.md` 를 `projects/<P>/out/검토_체크리스트.md` 로 복사.
2. 그 아래에 다음을 정리해 붙인다:
   - **숫자·이름·날짜 목록**: 영상·블로그·쓰레드·캡션에 나온 모든 숫자/고유명사/날짜와 위치(파일, 시각).
   - **잘림·중복 의심 시각**: verify.py 결과 그대로.
   - **영상에 없던 문장**: content-write 자기 검사 결과.
   - 완성 파일 목록: final.mp4, shorts, thumbs, blog.md, threads.md, 캡션.
3. 사용자에게: "체크리스트 세 가지(사실 / 지금 올려도 되는지 / 잘림·겹침)는 직접 확인해 주세요. 끝나면 '검토 끝'이라고 말해 주세요."
4. "올려도 돼?"라는 질문에 Claude 가 '된다'고 답하지 않는다. 확인할 지점을 알려주고 판단은 사용자에게 맡긴다.
