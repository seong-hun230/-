# 업로드 전 저품질 점검 + 일일 분석

## 1. 원고 점검 (자동)

```bash
python3 .claude/skills/blog-precheck/scripts/precheck.py blog/ --out reports/YYYY-MM-DD_업로드전점검.md
```

- `blog/` 아래 모든 워드 원고(.docx)를 읽는다. 본문은 '본문 (네이버에 붙여넣기)' 다음 줄부터 '태그' 전까지.
- 메인 키워드: 원고 머리말의 `메인 키워드: ○○`, 없으면 제목 앞부분(단지명).
- 필요한 것: pandoc.

| 항목 | 기준 | 감점 |
|---|---|---|
| 분양가·모델하우스 주소 (CLAUDE.md) | 금액(만원·억), 평당가, 할인율, 취득가, 혜택가, 모델하우스 주변 주소 | -40 |
| 광고 표시 | '분양 홍보 목적' 문구 | -15 |
| 분량 | 공백 제외 2,500~3,200자 | -5 / -15 |
| 메인 키워드 반복 | 본문 4~8회 권장, 11회 이상 '수정' | -5 / -15 |
| 과장·보장 표현 | 무조건, 100%, 확정 수익, 마감 임박, 로또 등 | 개당 -10 |
| AI 상투구 | '결론적으로' 등 4회 이상 | -5 |
| 문단 길이 | 300자 넘는 문단 | -3 |
| 글 안 중복 문장 | 같은 문장 반복 | -5 |
| 이미지 | 사진+배너 8장 이상 | -3 |
| 전화 유도 (CLAUDE.md) | 배너 3장 이상, 배너마다 번호 줄 | -3 / -5 |

점수: 85점 이상 '업로드 가능', 65~84 '수정 후 업로드', 64 이하 '업로드 보류'.

**원고끼리 유사도**: 6글자 조각 겹침 비율과 똑같은 문장(20자 이상) 수. 45% 이상 또는 똑같은 문장 5개 이상이면 '위험 — 다시 쓰기', 30% 이상 또는 2개 이상이면 '주의'.
같은 단지 글은 문장을 새로 쓰고 발행 간격을 3일 이상 둔다. 광고 표시·자료 기준일 같은 고정 문구도 글마다 표현을 바꾼다.

이 기준은 네이버 공식 수치가 아니다. 네이버는 '저품질' 기준을 공개하지 않으므로, 널리 알려진 위험 요인(유사문서, 키워드 남용, 과장 표현)을 보수적으로 잡은 값이다.

## 2. 발행 기록

발행한 글은 `blog/발행기록.md`에 한 줄씩 적는다. 점검 리포트에서 '(발행 완료)'로 표시되고, 새 원고와의 유사도 비교 대상이 된다.

```
- 2026-11-28 | 대전씨엘리오스위첸_블로그원고.docx | https://blog.naver.com/...
```

## 3. 블로그·카페 흐름 조사 (WebSearch)

이 환경에서는 네이버 블로그·카페에 직접 접속할 수 없고, 카페 글은 대부분 로그인해야 보인다. 그래서 웹 검색에 잡히는 공개 글·기사·커뮤니티 미리보기만 본다. 리포트에 이 한계를 적는다.

- 검색어(단지·지역에 맞게 바꾼다): `{지역} 오피스텔 분양`, `{단지명}`, `{역명} 오피스텔`, `오피스텔 주택수 세금 {연도}`, `{지역} 교통 호재 일정`, `{지역} 미분양`, `오피스텔 관리비 단점 실거주 후기`
- 정리할 것
  1. 사람들이 묻는 질문·걱정 (관리비, 전용률, 세금, 전입신고, 시세)
  2. 원고 사실이 바뀌었는지 (교통 개통 연도, 세제 특례 기한, 사업비) — 바뀌었으면 원고 수정 제안
  3. 경쟁 단지·시장 뉴스
  4. 다음 원고 소재 3개 (질문형 제목 + 메인 키워드 후보)
- 구체적 주장에는 출처 링크를 단다. 확인 안 된 것은 '확인 필요'로 적는다.
- 분양가·모델하우스 주소 규칙은 리포트의 '원고 소재 추천'에도 그대로 적용한다.

## 4. 일일 리포트

`reports/YYYY-MM-DD_일일분석.md` 하나로 만든다: ① 오늘 결론 3줄 ② 원고 점검 표 ③ 유사도 ④ 흐름 조사 ⑤ 해야 할 일. 커밋 후 작업 브랜치에 푸시한다.
