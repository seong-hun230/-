# STEP 6 글 쓰기 — 영상에서 '한 말'만 재료로

먼저 `workflow/rules/글쓰기규칙.md` 를 읽는다 (피드백 기록 포함).

## 재료
- `projects/<P>/work/cut.transcript.txt` 또는 `cut.transcript.json` 의 문장들 **만**.
- 쓰레드는 `workflow/rules/말투샘플/` 의 글로 말투를 맞춘다. 샘플이 없으면 사용자에게 2~3편 요청(그 전엔 영상 말투 그대로).

## 만들 것 (모두 `projects/<P>/out/`)
1. `blog.md` — 네이버 블로그
   - 제목 앞쪽에 키워드(사용자가 정해 주지 않았으면 영상에서 가장 많이 나온 핵심어로 제안하고 확인).
   - 사진 3~5장: 장면 시각을 골라 `python workflow/scripts/thumbnail.py frames projects/<P>/work/cut.mp4 <초> <초> <초> -o projects/<P>/out/blog_photos`, 본문에 `[사진1]` 위치 표시.
   - 강조 문장은 **굵게** + `(색: 빨강)` 하나만.
   - 끝에 `[지도: 장소명]` (장소명은 사용자에게 확인).
2. `threads.md` — 3개로 나눈 글. 누구에게 → 바로 방법 → 짧은 내 생각. 각 500자 이내. 사진은 1번 글에만.
3. `caption_reels.txt` — 인스타 캡션. 첫 줄에 검색될 단어. 해시태그는 넣지 않음(발행 초안에서 5개까지 따로).
4. `youtube_description.txt` — 유튜브 설명. 자료 링크 자리 표시.

## 끝나기 전에 자기 검사 (필수)
- 쓴 글의 문장마다 영상 받아쓰기에 근거가 있는지 대조한다.
- 영상에 없는 숫자·사례·경험이 있으면 지운다.
- 보고할 때 "영상에 없는 내용: 없음" 또는 "다음 문장은 영상에 없어 확인 필요: …"를 반드시 적는다.
